# API 参考

以下接口仅用于文档展示，不提供真实服务。

## 查询文档列表

- 请求方法：GET
- 请求路径：/api/docs
- 功能：返回文档条目列表。

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"},
    {"id": 2, "title": "关于本项目"}
  ]
}
```

## 查询单篇文档

- 请求方法：GET
- 请求路径：/api/docs/{id}
- 功能：按编号返回一篇文档的标题与正文摘要。

### 参数说明

| 参数 | 位置 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | path | 是 | 文档编号，正整数 |
| fields | query | 否 | 需要返回的字段，逗号分隔 |

### 返回示例

```json
{
  "id": 1,
  "title": "使用指南",
  "summary": "修改文档、本地预览、推送发布的完整流程。"
}
```

### 错误码

| 状态码 | 含义 |
| --- | --- |
| 200 | 请求成功 |
| 404 | 指定编号的文档不存在 |
| 500 | 服务内部错误 |

## 用 curl 试一下（本地无服务时会连接失败）

```bash
curl -s https://orihamaru.github.io/my-docs/api/ | head -n 20
```
